# DeviceTrust Mobile Marketplace UI

Pakistan's premier fraud-free smartphone provenance exchange UI, featuring PTA DIRBS verification and CPLC theft telemetry.

---

## 🚀 Running Locally

The local server is already running at:
**[http://localhost:3000](http://localhost:3000)**

To run it again anytime:

```bash
npm start
# or
node server.js
```

---

## 📱 Available Routes

| Route | Screen Description |
|---|---|
| [`http://localhost:3000/`](http://localhost:3000/) | **Interactive Mobile Device Studio** (iPhone 15 / Pixel 8 Frame, Screen Switcher, Journey Stepper) |
| [`http://localhost:3000/splash`](http://localhost:3000/splash) | **Splash Screen** with live telemetry sync animation |
| [`http://localhost:3000/onboarding`](http://localhost:3000/onboarding) | **Onboarding Carousel** (Curated Inventory, Anti-Theft Scan, Title Transfer) |
| [`http://localhost:3000/login`](http://localhost:3000/login) | **Login & Registration** (+92 Pak Phone auth, Regional Hub Selector) |
| [`http://localhost:3000/home`](http://localhost:3000/home) | **Home Marketplace** (Live Search, Verified Devices, Instant IMEI Check Modal) |
| [`http://localhost:3000/design`](http://localhost:3000/design) | **Design System Specifications** (Fintech colors, Typography & Elevation rules) |

## ⌨️ Studio Keyboard Shortcuts

- Press <kbd>1</kbd> → Splash Screen
- Press <kbd>2</kbd> → Onboarding
- Press <kbd>3</kbd> → Login / Registration
- Press <kbd>4</kbd> → Marketplace Home
- Press <kbd>R</kbd> → Reload active screen
